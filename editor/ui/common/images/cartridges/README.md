### agb-e06-01-sram-battery.jpg

- Photo : 3615Retro, Game Boy hardware database, CC BY-SA 4.0.
- Source : https://gbhwdb.gekkio.fi/cartridges/AGB-AFZP-0/3615retro-1.html
- Original : https://gbhwdb.gekkio.fi/static/AGB-AFZP-0/3615retro-1_02_pcb_front.jpg
- F-Zero: Maximum Velocity, AGB-E06-01 ; ROM Macronix MX23L3206-12B (4 Mio), SRAM Hyundai GM76V256CLLFW10 (32 Kio), pile CR1616.

recto/verso et des repères dessinés par l’interface sur le recto assemblé. Les originaux
