# Ressources incluses dans le modèle Basic

Ce modèle inclut des palettes prêtes à l'emploi :

| Palette | Origine |
| --- | --- |
| DMG (GB Default), DMG (GB Default) (BG) | Créées pour Backstage |
| Microsoft Windows 16 | Palette système historique (16 couleurs VGA/Windows) |
| Commodore 64 | Palette système historique |
| PICO-8 | Lexaloffle Games |

Les licences des polices incluses dans ce modèle sont disponibles dans le dossier `licenses/`.
